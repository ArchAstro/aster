  <files>

  <action>
1. Update `src/cli/commands.rs`:
   - Add `Logs` variant to Commands enum:
     ```rust
     /// View logs from the last run
     Logs {
         /// Specific target to view (e.g., //services/api:test)
         target: Option<String>,
     },
     ```

2. Update `src/main.rs`:
   - Import LogStore from executor::logs
   - Add handler for Commands::Logs:

   **Without target argument (`aster logs`):**
   - Load latest run via LogStore::load_latest()
   - If no previous run: print "No previous run found" and exit successfully
   - Print header: "Last run: {target} ({timestamp})"
   - For each result in run.results:
     - Print status icon (green checkmark for passed, red X for failed, yellow dash for skipped)
     - Print target address
   - Print footer: "Use `aster logs <target>` to view full output"

   **With target argument (`aster logs //project:target`):**
   - Load via LogStore::get_target_log(address)
   - If not found: exit silently (empty output, per CONTEXT.md - not an error)
   - If found:
     - Print separator: "--- {address} ---"
     - Print full output
     - Print status line: "[STATUS] {address} ({duration_ms}ms)"

3. Support both address formats:
   - `//project:target` (full target address)
   - `//project target` (project address + target name, split by space)
   - Normalize to full target address format

4. JSON output for logs command:
   - `aster logs --json`: output RunLog as JSON
   - `aster logs <target> --json`: output TargetLog as JSON (or empty object if not found)
  </action>

    - After running `aster test //project`, `aster logs` shows the run summary
    - `aster logs //project:test` shows full output for that target

    - `aster logs --json` outputs JSON
    - `cargo test` passes
  </verify>

Example test structure:
```rust
use assert_cmd::Command;
use predicates::prelude::*;

#[test]
fn test_list_json_is_valid() {
    let tmp = setup_workspace_with_projects();

    let mut cmd = Command::cargo_bin("aster").unwrap();
    cmd.current_dir(tmp.path())
        .arg("list")
        .arg("--json");

    cmd.assert()
        .success()
        .stdout(predicate::str::is_match(r#"\["#).unwrap());  // Starts with array

    // Parse output as JSON
    let output = cmd.output().unwrap();
    let parsed: Vec<serde_json::Value> = serde_json::from_slice(&output.stdout).unwrap();
    assert!(!parsed.is_empty());
}
```
