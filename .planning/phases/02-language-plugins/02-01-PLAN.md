<task type="auto">
  <name>Task 2: Implement Python plugin with TOML-based pyproject.toml parsing</name>
  <files>src/plugins/python.rs</files>
  <action>
Create src/plugins/python.rs implementing LanguagePlugin trait:

1. Define PythonPlugin struct implementing LanguagePlugin:
   - name() returns "python"
   - marker_files() returns &["pyproject.toml"]

2. Define serde structs for pyproject.toml parsing:
   ```rust
   #[derive(Deserialize)]
   struct PyProjectToml {
       project: Option<PepProject>,
       tool: Option<ToolSection>,
   }

   #[derive(Deserialize)]
   struct PepProject {
       name: Option<String>,
       dependencies: Option<Vec<String>>, // PEP 621 format
   }

   #[derive(Deserialize)]
   struct ToolSection {
       poetry: Option<PoetrySection>,
   }

   #[derive(Deserialize)]
   struct PoetrySection {
       name: Option<String>,
       dependencies: Option<HashMap<String, PoetryDependency>>,
   }

   // Use #[serde(untagged)] for dependency variants
   #[derive(Deserialize)]
   #[serde(untagged)]
   enum PoetryDependency {
       Simple(String),  // "^1.0"
       Complex { path: Option<String>, ... },
   }
   ```

3. parse_project() extracts project name:
   - Priority: project.name (PEP 621) > tool.poetry.name
   - Error if neither found

4. parse_dependencies() extracts path dependencies:
   - Poetry format: `dep = {path = "../lib"}` or `dep = {path = "../lib", develop = true}`
   - PEP 621 format: `dep @ file:../lib` in dependencies array
   - Use regex to parse PEP 621 editable installs: `^(\S+)\s*@\s*file:(.+)$`
   - Return Vec<LocalDependency>

5. Add comprehensive tests:
   - test_parse_pep621_project (project.name extraction)
   - test_parse_poetry_project (tool.poetry.name extraction)
   - test_parse_poetry_path_dependency
   - test_parse_poetry_path_with_develop
   - test_parse_pep621_file_dependency
   - test_priority_pep621_over_poetry (project.name wins)
   - test_missing_name (error case)
   - test_no_path_dependencies (empty vec)
  </action>
  <verify>`cargo test python` passes all Python plugin tests</verify>
  <done>PythonPlugin extracts name from project/tool.poetry and path dependencies from Poetry/PEP621 formats</done>
</task>
