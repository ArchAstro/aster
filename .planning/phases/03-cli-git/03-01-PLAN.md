  <action>
Create the executor module for running target commands on projects:

1. Create `src/executor/mod.rs`:
   - Export runner module

2. Create `src/executor/runner.rs`:
   - `ExecutionResult` struct: address, success (bool), output (String), duration_ms (u128)
   - `Executor` struct with `execute()` method
   - Execute commands using `std::process::Command`
   - Buffer stdout+stderr together per-project
   - Print grouped output as each project completes (project header, output block)
   - Continue on failure (collect all results, report failures at end)
   - For parallel execution respecting dependencies:
     - Compute "levels" in DAG (level 0 = no deps, level 1 = depends only on level 0, etc.)
     - Execute each level in parallel using std::thread + mpsc
     - Wait for level to complete before starting next level
   - Use workspace root to find correct working directory for each project
   - Parse command string with simple whitespace split (shell_words not needed for v1)

3. Add to `src/lib.rs`:
   - `pub mod executor;`
   - Re-export `Executor`, `ExecutionResult`

No new dependencies needed - use std::process, std::thread, std::sync::mpsc from stdlib.

Key implementation detail: For each project, look up target command from DiscoveredProject.targets HashMap. If target not found, skip with informative message (not an error).
  </action>
  <verify>
cargo build --lib compiles without errors
cargo test executor passes
  </verify>
  <done>
Executor runs commands in parallel by DAG level with grouped output buffering.
  </done>
</task>
